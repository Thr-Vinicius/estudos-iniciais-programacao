# Automações em Python

Scripts de teste usando bibliotecas e comandos do sistema.

## Arquivos

- `coordenadas_mouse_hyprland.py`: mostra a posição do cursor no Hyprland usando `hyprctl`.
- `escrever_automatico.py`: usa PyAutoGUI para escrever texto automaticamente.
- `cnae_auto.py`: rascunho de automação para preenchimento de dados com PyAutoGUI.

## Aviso

Scripts com PyAutoGUI dependem das coordenadas da tela e precisam ser ajustados antes de usar em outro computador.
