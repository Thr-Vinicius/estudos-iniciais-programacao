# Estudos Iniciais de Programação

> **Status:** Repositório arquivado. Este conteúdo reúne exercícios e pequenos projetos antigos preservados como registro da minha evolução em programação.

Este repositório reúne atividades, exercícios e pequenos projetos desenvolvidos durante meus primeiros estudos de programação.

Os arquivos foram originalmente criados de forma separada ao longo do aprendizado e posteriormente organizados neste repositório para preservar esse material e registrar minha evolução.

## Conteúdo

- **01-python-basico** — exercícios de lógica, variáveis, listas, condicionais, loops, funções e entrada de dados.
- **02-automacoes** — experimentos simples de automação com Python e PyAutoGUI.
- **03-web** — exercícios de HTML/CSS e pequenos experimentos de desenvolvimento web.

## Objetivo

Preservar meus primeiros códigos e atividades como registro da evolução no aprendizado de programação.

Alguns códigos possuem soluções simples, estruturas pouco refinadas ou práticas que hoje eu faria de forma diferente, justamente por representarem uma fase inicial dos meus estudos.

## Tecnologias

- Python
- HTML
- CSS
- JavaScript
- Node.js

## Observação

Este repositório não representa meu nível atual de desenvolvimento. Ele é mantido como um arquivo histórico dos meus primeiros exercícios e experimentos com programação.
