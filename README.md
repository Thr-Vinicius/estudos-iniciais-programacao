# Aprendendo Programação

Repositório com exercícios e pequenos projetos feitos durante meus estudos de programação.

## Conteúdo

- **01-python-basico**: exercícios de lógica, variáveis, listas, `if`, `while`, `for`, funções e entradas do usuário.
- **02-automacoes**: testes de automação com Python, coordenadas do mouse e PyAutoGUI.
- **03-web**: exercícios de HTML/CSS e um pequeno projeto web com Node.js.

## Objetivo

Registrar minha evolução nos estudos, praticar lógica de programação e organizar meus primeiros códigos no GitHub.

## Tecnologias usadas

- Python
- HTML
- CSS
- JavaScript / Node.js

## Observação

Este repositório é uma coleção de estudos. Alguns códigos são simples de propósito, pois representam a evolução desde os primeiros exercícios.
